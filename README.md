# nong healjai

Dev of nurse doll.

โปรเจกต์ `nong healjai` เป็นพื้นที่เริ่มต้นสำหรับจัดเก็บไฟล์และพัฒนาไอเดียบน GitHub

## Overview

This repository contains the starting files for the `nong healjai` project.

## Files

- `index.html` - a simple starter page for the project
- `arduino/nong_healjai_doll/` - Arduino Nano code for the nurse doll motor and MP3 behavior
- `.gitignore` - common files and folders to keep out of Git

## Getting Started

Open `index.html` in a browser to view the starter page.

## Arduino Doll Project

Open `arduino/nong_healjai_doll/nong_healjai_doll.ino` in Arduino IDE. The sketch uses a pull-up button to play MP3 track `0001.mp3` on a DFPlayer Mini and rotate a stepper motor forward 180 degrees, then back 180 degrees.
